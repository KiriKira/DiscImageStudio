# DVD物理坐标反射误差抖动：设计与原型

> 主程序现已增加原生 .NET 实验模式，见[原生功能说明](PHYSICAL_DITHER_NATIVE.md)。本文保留为 Python 参考原型的设计与用法；原生功能不依赖 Python。
## 目标与边界

把图片转换从“灰度值直接决定黑白码字概率”，改为“目标照片亮度 → 多条件光学反演 → 物理坐标量化 → 现有合法码字生成”。核心对象是包含多个码字的一小块**纹理单元**，不是一个可以任意涂黑/涂白的光学坑。

初版以DVD现有Q=A5/92纹理为两个端点。固定轨距、局部轨道方向、有限光源、有限相机距离与波长参与光学计算。材料参数、照明和影调独立配置；未测材料必须标记为hypothetical。设计不要求改动CD/BD、GUI、项目文件或刻录编码规则。

## 一、像素的物理定义

盘面采用毫米坐标(x,y)，中心为原点，局部径向为e_r，切向为e_t。网格为等物理尺寸的正方形，避免等角度格子在外圈变宽。图像行向下、物理y向上，与现有RasterImage.SampleDisc一致。

输入格距h可以先扫描40/80 µm等可运行尺度。h控制纹理混合的空间尺度，不等同于DVD通道位长；现有几何中16通道位约2.13 µm，名义轨距约0.74 µm。一个40 µm格子包含许多轨道/码字。图像量化只决定局部选择哪种payload纹理，后续ECC、同步、扰码补偿和EFMPlus仍由现有链路完成。

最细尺度并不自动最好：跨码字切换可能改变有效频谱，粗尺度可能显颗粒。模型中的独立单元和面积混合都是要靠标靶验证的近似。

## 二、有效反射模型

对纹理k、出射/入射方向v/s、波长λ，定义三部分非负BRDF：

`f_k(s,v,λ) = a_d/π + a_s K_s(q) + a_g [K_g(q−λ/d·e_r)+K_g(q+λ/d·e_r)]/2`

这里q=s_xy+v_xy，方向均从盘面朝外；d为轨距。K为投影方向余弦平面中的归一化高斯，径向/切向宽度允许不同。K_s中心在零级镜面条件q=0，K_g中心遵循±1级轨道光栅条件。两种纹理可以有不同的反射预算和瓣宽。初版各预算不随波长变化，光栅中心随波长变化。

这不是Maxwell求解器，也不是用跳变密度直接算反射率。它是具有物理约束、可拟合的有效模型。其优势是几个性质可以明确保证：

- **非负性**：所有预算非负。
- **被动性/能量上界**：a_d+a_s+a_g≤1。对出射半球积分时，`cosθ dΩ = du_x du_y`；每个K在整个投影平面上积分为1，在可传播单位圆内积分≤1。因此每个分量的半球反射不超过对应预算，不会产生额外能量。
- **互易性**：交换s与v，q不变，BRDF不变。
- **几何方向性**：盘面不同方位的e_r/e_t不同，同一个灯在不同位置产生不同响应；不把整个盘当作同一块平面镜。

未反射部分由模型视为损耗，不进一步拆分吸收/透射。尚未包含AZO染料多层干涉、矢量偏振、沿轨道的真实码型频谱、相邻单元的相干交叉项、全盘ECC纹理和盘面翘曲。高斯瓣是有效参数，不能当成已测的坑尺寸。

### 有限光源积分

所有光源为朝向盘面的水平矩形均匀发光面。按面积采样其每一部分，累加：

`R_k(x,v) = Σλ wλ Σlight_samples Lλ · f_k(s,v,λ) · cosθ_i · cosθ_light · ΔA / distance²`

光源位置、尺寸和相机位置均以毫米输入。wλ是已经合并了光谱和传感器响应的相对权重，示例权重不宣称等于某台相机的真实光谱响应。有效模型输出相对辐亮度，不自动调曝光。

初版先在粗网格算R0/R1，再双线性插值。光源积分和粗网格分别有收敛测试；实际使用窄瓣或非常小的光源时仍应加密检查。

## 三、目标亮度与混合反演

1. sRGB逐通道线性化，再转Rec.709亮度；透明区在线性光中合成白底。
2. 独立影调参数作用于线性亮度Y；不再把“抖动强度”兼作对比度曲线。
3. 每个观察条件j，用两个纹理全盘亮度中位数确定该条件的目标端点L_j/H_j，目标为`T_j(x)=L_j+(H_j−L_j)·Y(x)`。这使目标照片在该灯位下保持均匀影调，而不是把不均匀照明直接烘进目标。
4. 以面积混合近似预测`P_j(x,p)=R0_j(x)+p·ΔR_j(x)`，其中ΔR=R1−R0。
5. 求共同的混合比例：

`p*(x)=clip[ Σ_j w_j ΔR_j(T_j−R0_j) / Σ_j w_j ΔR_j², 0, 1 ]`

这正是有界加权最小二乘解。权重是显式的条件权重，不暗中按每张图自动归一化曝光。当某处两种纹理响应相同，标记不可观测；当目标超出可混合范围，标记裁剪；多条件间互相矛盾会留下连续拟合残差，不能通过抖动凭空消除。

例如两个灯位分别让纹理92比A5更亮和更暗，不能保证两个灯位同时得到同样的正相图案。算法可折中，也必须报告冲突。

## 四、反射误差扩散

普通误差扩散传播的是一个0–255灰度误差。这里传播的是各观察条件组成的**辐亮度误差向量**。

对一个物理网格单元：

1. 目标有效响应为`R0+p*ΔR`，加上前面单元传来的误差。
2. 在加权辐亮度距离中选择纹理0或1。
3. 给二选一的分界加入很小的、非平铺哈希阈值扰动（等效比例阈值±0.05），降低规则半色调锁相的风险。扰动不改变输入影调，产生的误差仍进入反馈。
4. 计算实际反射残差，仅把沿本地ΔR方向、可由更换纹理纠正的分量继续传播。无法通过两种纹理纠正的正交分量不允许不断积累。
5. 在等毫米x/y格子上蛇形扫描，按7/3/5/1权重向尚未访问的有效邻居扩散；边界重新归一化，不向中心孔传播。

这是一种**物理响应感知的噪声整形误差扩散**。它不是已证明各向同性的蓝噪声，仍可能有扫描方向纹理；“用了物理模型”不等于消除了所有摩尔纹。相比逐字节哈希，它对低频灰阶误差有反馈约束，并且在量化决策中考虑了实际模型下的纹理反差。

初版没有全局直接二值搜索(DBS)，也没有声称直接优化完整相机PSF。输出后用多个物理模糊尺度比较误差，帮助判断量化是否改善可见层次。未来可在该结果上加入多条件PSF目标下的交换优化，但必须单独验证收益和运行成本。

## 五、预览与编码输出

输出0/255不透明PNG，固定映射到A5/92；保存配置、源图哈希、格距、种子、灯位与指标。原型预览采用有效反射图加高斯观察模糊，目标/预测共用显示尺度。图外与孔内的预览区域黑色只是遮罩表示，不代表真实盘片外观。

PNG进入现有DVD路径时必须保留尺寸和采样外半径，并关闭再次抖动、gamma和亮度偏移。现有二值图最近邻分支保留纹理比例；正常编码、读盘兼容和文件范围约束继续适用。假设模型没有计算这些派生字段对反射的贡献，因此仅能把预处理图视为纹理意图，而不是逐通道位保证的物理图案。

## 六、43523实盘校准

应在同一盘片批次、刻录机、速度和读取兼容性配方下，写入两种纯纹理和25%/50%/75%混合块，在多个半径和方位重复。每个混合比例再比较几个物理格距。

固定相机RAW、曝光、白平衡和灯位，先扣黑电平，再估计相对线性亮度。光源光谱/亮度未知时，通常只能标定相对响应，不能声称识别了绝对反射率。拟合反射预算/瓣宽需要多个入射和观察方向；单张未知照明的照片不足以唯一确定材料参数。

拟合时保持非负预算、总预算≤1，并留出未参与拟合的角度与半径验证。应记录测量证据、拍摄几何、残差和硬件元数据；只有通过验证的配置才标记measured。如果25/50/75%块明显不满足线性混合，应升级为混合比例/格距相关响应表，不能继续把端点线性插值当作事实。

## 七、已验证与未验证

原型测试覆盖能量上界、互易性、光源/网格收敛、可反相的混合求解、不可能同时满足的多视图目标、无对比度区域、端点/孔洞、平均灰阶和低频噪声。测试图可走现有CLI生成32扇区样本，并通过单个ECC块的完整编码到619008个通道电平。

这些是数值与接口验证。尚未进行43523实盘刻录、材料参数拟合、全盘回读或摄影对照；不能声称比默认转换在真实盘片上更清楚。默认参数和推荐格距也不构成已测最优配置。
