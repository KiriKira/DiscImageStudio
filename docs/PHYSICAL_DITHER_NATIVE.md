# 原生DVD物理转换（实验性）

## 使用

设计页的DVD影调区域可以启用“物理优化”，导入原生材料/灯位JSON，选择20、40或80微米网格，再点击刷新预览。输入改变后结果会清空，须手动重新计算。下拉框可查看按面积平均的抖动灰阶、响应受限的区域和各灯位的预测外观。预测外观使用相同条件下的目标/结果显示尺度，不能当成43523实拍保证。

物理模式会停用旧影调控件。v3默认保留照片的感知灰阶密度：sRGB先在线性亮度空间重采样，再编码回感知灰阶，128灰对应约50.2%的白点。`toneExponent`调节该密度曲线；`toneEncoding: "linear"`才使用线性亮度作为点比例（128灰约21.6%），适合明确需要辐射度映射的标定流程。

`reflectanceCompensation`默认0，避免用未实测材料和灯位的反演结果吃掉照片层次。需要补偿时可设0..1；`maximumToneShift`默认0.08，将每个位置的密度修正幅度限制在8个百分点内，最后裁到0..1。参数显式保存在工程和缓存身份中。材料/光谱/灯位可在高级JSON中编辑，或者直接导入配置文件。`provenance`必须声明`hypothetical`或`measured`；后者需要`evidence`。证据是用户提供的测量记录，软件不认证材料实测准确性。

设计页改变物理设置时仅清空旧结果，保留已导入的源图，刷新按钮仍可用；计算进度和错误会显示在按钮下方。离开设计页会取消尚未完成的设计预览，预览页再按需要计算。

预览页的“标定预览”会复用与导出/刻录相同的物理转换缓存，读取完整`masked.png`，显式保留二值/透明采样，再按实测几何投影。状态显示“物理抖动”，不以旧影调滑块的0%表示预处理抖动。它仍是几何投影预览；各灯位的预测外观请在设计页下拉框查看。关闭物理模式会恢复原有标定和影调路径。物理模式不会在设计页背后自动启动标定计算。

首次完整计算可能较慢，尤其是20微米、多灯位、多尺度优化；可先用80微米比较设置。导出和刻录准备使用可取消的任务进度，并缓存完整二值结果；不会在开始实际写盘后运行物理优化。若设备容量要求改变绘图区，先修改工程容量、重新计算，再刻录。

默认功能关闭。启用时工程内嵌材料/灯位快照并保存为schema 3；普通工程继续保存为schema 2。旧版程序不能读取schema 3。缺少设置的旧工程保留原有算法。此功能仅用于DVD；通用Core只持久化模块JSON，光学和码字逻辑由DVD模块处理。

## 命令行

原生命令不需要Python。以下参数直接传给已构建的`disc-image-studio`，或放在`dotnet run --project src/DiscImageStudio.Cli -c Release --`之后。

生成标靶和原生配置模板：

```text
dvd-physical-target --output-dir artifacts/physical-calibration --size 6001
```

它生成40/80/160微米纹理比例标靶、测量CSV、`profile.json`和布局说明。输出目录必须为空。标靶为58 mm半径画布，25–55 mm内分三圈，每圈20个面板；A5/92的0/25/50/75/100%比例在四个方位重复。小尺寸只能用于流程检查；小于栅格间距的纹理尺度会欠采样。首版不自动从照片拟合材料参数。

独立转换排好版的正方形盘面图：

```text
dvd-physical-convert --image square-layout.png --profile artifacts/physical-calibration/profile.json --output-dir artifacts/physical-cache --cell-um 40 --canvas-radius-mm 58 --inner-radius-mm 24.5 --outer-radius-mm 58
```

省略`--profile`使用假设模型；`--passes 0..4`覆盖优化轮数。独立转换默认轨距740 nm。若需严格匹配工程生成几何，使用下面的`solve --physical-profile`或GUI流程，它们按扇区数、位长和轨距多项式计算本地几何。

直接经物理准备生成一个32扇区冒烟样本（不是完整刻录镜像）：

```text
solve --image square-layout.png --physical-profile artifacts/physical-calibration/profile.json --total-sectors 2297888 --inner-radius-mm 24.5 --outer-radius-mm 58 --fill-sectors 32 --iso-output artifacts/physical-smoke.iso
```

实际输出必须使用已确认的盘片几何和可写范围；示例容量不代表43523的实测可写容量。读取兼容性配方必须与配置`recipe`一致，不匹配会报错，程序不会静默关闭兼容性。

## 输出和接口

统一入口为`DvdPhysicalConversion.Prepare`，DVD布局适配入口为`DvdPhysicalPreparation.Prepare`。`DvdImageRequest.Physical`可让原生API调用方执行同一准备流程。GUI导出和刻录复用内容哈希缓存。

缓存包括：

- `density.png`：面积平均后的抖动灰阶预览，遮罩边缘保留覆盖alpha，界面继续使用高质量缩放；不以少数采样点替代高分辨率抖动。
- `binary.png`：不透明的0/255纹理图，用于检查码字选择。
- `masked.png`：真正用于生成的二值RGBA图，保留孔洞、透明排除区和文件布局绘图区遮罩。后续必须显式启用`physical-binary`采样。
- `view-N.png`与`target-N.png`：各照明条件的预测和目标亮度，使用一致尺度并经sRGB显示编码；数值报告仍在线性亮度空间。预览按面积缩小二值图，是显示用途的近似，不代替最终栅格。
- `diagnostic.png`：灰度85表示自然影调端点、170表示两种纹理不可区分、255表示启用补偿后的密度被裁剪；它是响应诊断，不是反射率测量图。
- `report.json`：输入哈希、设置快照、几何、条件端点、光学检查点、全局参考拟合RMS、反演原始越界比例、实际密度裁剪/不可观测比例、输入/目标/输出平均点密度和每轮接受的目标函数下降量。
- `result.json`：缓存提交后的结果索引。

缓存按源图内容、模型版本、灯位、光谱、影调、种子、网格、绘图区和几何生成键，并通过临时目录原子提交。中断、失败或配置变化不会把半成品当作完整缓存。读取兼容性配方属于模型身份；文件内容仍由已有文件系统/刻录路径处理。

物理RGBA采样是显式选项：验证0/255灰度和0/255 alpha、使用最近邻，关闭依赖不透明输入的SIMD和稳定区域复用。普通模式保留原有采样行为。文件区域、孔洞和透明排除区不接收误差扩散。

## 模型和优化

有效BRDF由宽角散射、镜面瓣、径向±1级衍射瓣组成；预算非负且总和≤1，投影方向高斯核具有半球能量上界并满足互易性。光源为有限矩形面积光源，传感器加权光谱可全局设置，单个观察条件可以覆盖光谱。局部轨距来自工程曲线。

输入在线性亮度空间做面积降采样/双线性上采样，再按所选影调编码获得目标密度p。蛇形Floyd–Steinberg密度误差扩散及固定种子的阈值微扰生成细密抖动；即使两种纹理的反射完全相同，也继续扩散灰阶。

反射目标为每个位置的局部混合`R0 + (R1-R0)*p`，保留自然的光照起伏。全局反演只用于显式启用的有界补偿与诊断。后处理使用点密度误差与归一化反射误差的加权目标：密度权重1，所有灯位的反射误差总权重0.25。各灯位以光学网格上纹理差值的RMS归一化，避免辐射度单位支配灰阶。

20/60/180微米高斯观察尺度各使用1/0.5/0.25权重，σ下限为1.2个网格单元，使评分衡量空间平均后的半色调。该下限是数字半色调评价足迹，不代表盘片实际光学模糊或可见角度。只允许同一16×16区域内的相邻异色交换，保持各区域初始抖动白点数完全不变；不再执行单点翻转。只有降低目标函数的交换才被接受。

为限制整盘成本，每轮访问四分之一、按相位轮换的候选位置；默认四轮覆盖各列相位。这是有界的局部优化，不是全量穷举DBS。计算使用128格块，密度约束使用16格块；卷积使用跨块halo和更新后的误差，误差扩散跨行连续。轮次、相位和访问顺序固定，与线程调度无关。改进量低于当前误差估计的0.01%时提前停止。

输出上限8192×8192；不会静默改成较粗网格。当前实现为CPU计算，精细模式可能需要数分钟甚至更久。附带模型仍是有效纹理近似：缺少实测材料时，不代表完整坑形、电磁场、多层染料干涉或跨单元相干效应，也不能保证可见角度拓宽。

## 验证

原生DVD自检覆盖互易性、能量预算、二值/透明遮罩、缓存失效和取消，以及7级灰阶密度/单调性、无光学对比仍保留抖动、显式线性影调、有界反射补偿、优化跨块与遮罩边缘的16×16白点数守恒。Windows架构测试增加了模块路由和schema 3保存/恢复/关闭新模式的回归。Python工具保留为数值参考；光学检查点可用于独立对照。

Linux环境可交叉编译WPF，但无法运行WindowsDesktop测试；Windows CI负责完整架构测试，并仍需人工检查配置导入、刷新、取消和实际预览。实盘效果需要同盘片/刻录机/速度/兼容性配方下的固定曝光对照，尚未作此验证。
